# LAÇO — Pacote de Planejamento

Software **vendido para clínicas** que atendem crianças com TEA. A clínica pré-cadastra a criança e entrega à família um código de ativação do app; a família aprova **cada profissional** antes de qualquer acesso clínico. Aderente à LGPD.

**Status:** planejamento completo · código ainda **não** iniciado.
